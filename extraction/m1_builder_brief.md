# M1 builder brief (I139), fixed 15/11/2026 before any builder was written by agents

Folder: <workdir>/. Python always `python -I`. No web access, no downloads (if a needed NHANES file is missing, say so in notes and in your report; do not fetch it).

Task: for each of your papers write tools/m1_specs/<rec_id>.py, a builder following the contract in tools/m1_lib_i139.py and the worked example tools/m1_specs/f1ad3fb0ff.py. The builder reconstructs the paper's FIRST-COMBINATION specification of its main estimate (prereg_i139_v7_en.md section 6 M1 and section 3.2 step 7).

Inputs per paper: the locked row of extraction/spec_table_i139.json (cycles, population, n_analytic, outcome_main/definition, egfr_equation, uacr_threshold, weight_variable, cycle_pooling, model_label, exposure_scale, estimate, covariates_final, ambiguities), and the full text fulltext_txt/<rec_id>.txt (source XML/PDF in fulltext/ when a formula or table is missing from the text). Index: use lib.INDEX[key] with the key in tools/recon_i139.py CFG for that rec_id, or lib.DIET[rec_id](df, reading=1) for dietary papers (tools/diet_indices_i139.py; read its notes extraction/diet_recon_notes_i139.md).

Rules (these protect the pre-registration; follow them exactly):
1. Readings: every point listed in the spec `ambiguities` uses reading_1. Any further point the text leaves open: choose the most literal reading of the paper's own words (else the most common NHANES convention) and write it in `readings` BEFORE you first execute the builder.
2. You may run ONLY `python -I tools/m1_check_i139.py <rec_id>` (it builds without fitting). Never run tools/m1_run_i139.py, never fit any model, never compute an OR or an outcome prevalence yourself.
3. After the first execution you may fix only technical faults (crash, wrong column name, a term that is all missing or constant, a unit error against the paper's stated unit). Never change a reading because of the analysed n. Log every post-run change in `notes` with its reason.
4. Domain = the paper's analytic population: age limits, pregnancy, disease restriction (diagnosis definition as the paper states), the paper's listed exclusions that are definable in public files (e.g. cancer MCQ220, dialysis KIQ025, missing exposure/outcome). Complete-case on covariates is applied automatically by the fit (do not drop rows from df; express exclusions in `domain`).
5. Outcome: the paper's definition and threshold (">" vs ">=" as reading_1), its eGFR equation (CKD-EPI 2009 with race when version not stated and race is mentioned or not; 2021 only when stated). Columns available: uacr, scr, egfr_ckdepi2009, egfr_ckdepi2021 from nhanes_core.
6. Exposure scale: as in the spec (per unit, per SD via lib.sd_scale on the domain, per 1000 units = x/1000, quantile contrast via lib.quantile_dummies cut on the domain with unweighted quantiles as reading_1 unless the paper states weighted, fixed cut points as written). `target` = the term whose OR equals the reported estimate.
7. Covariates: the spec's covariates_final, each coded as the paper defines (categories, reference levels). Available harmonised columns: age, female, race1 (RIDRETH1), race3 (RIDRETH3, 2011+), educ3, educ_raw, pir, smoking (never/former/current), bmi, waist, height, weight, dx_diabetes, dx_hypertension, diabetes_any, hypertension_any_140/130, cvd_history, sbp, dbp, glucose, hba1c, insulin, tg, ldl, hdl, tc, scr, egfr_*, uacr, uric_acid, alt, ast, ggt, albumin_serum, bun, calcium, wbc, neut_n, lymph_n, mono_n, platelets, hgb, rdw, crp_mgL, cotinine, copper, zinc. Anything else via lib.raw(df, lib.stems("<FILE>"), "<COLUMN>") from downloaded files: DEMO (DMDMARTL marital), ALQ, PAQ (+PAQIAF 1999-2006), SMQ, DIQ, BPQ (BPQ050A, BPQ100D), MCQ (MCQ220 cancer, MCQ160L liver), KIQ_U (KIQ026 kidney stones, KIQ025 dialysis; 1999-2000 absent), RXQ_RX via lib.rx_any(df, regex), DR1TOT/DR2TOT (energy), DPQ, SLQ, HIQ (2011-2012 only). Check the CDC codebook meaning of codes from the column values and the folder data-external/nhanes-extra/codebooks/ if present. Missing codes 7/9/77/99 stay missing.
8. Weight: the paper's reading_1 (spec weight_variable/cycle_pooling and the "survey weighting" ambiguity). Weighted: lib.pooled_weight(df, kind) with kind fasting/mec/interview by the smallest subsample the paper uses. If reading_1 is unweighted, weight None.
9. Not testable: if the specification cannot be reconstructed from public CDC files (an essential variable absent, e.g. a cycle's data file not public), return {"not_testable": "<reason>"} and explain.
10. No em dashes in notes; numbers truncated.

Report back per paper: builder written yes/no or not_testable with reason, readings decided beyond the spec, post-run technical fixes, and the analysed n from m1_check (n only).
